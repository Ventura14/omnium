# Alimentos pendientes de dar de alta

Ninguno de estos existe en BEDCA bajo ningún nombre buscado. No se
inventan datos nutricionales (regla dura, CLAUDE.md) — entran a mano
desde etiqueta o fuente externa cuando el usuario los compre / los
busque, no antes.

| Alimento | Por qué falta | Fuente cuando entre |
|---|---|---|
| Proteína de suero (whey) | No existe en BEDCA | Etiqueta del bote |
| Pasta sin gluten (maíz o arroz) | No existe en BEDCA | Etiqueta |
| Maíz dulce en conserva | No existe en BEDCA | Etiqueta |
| Queso fresco batido | No existe en BEDCA | Etiqueta |
| Abadejo | No existe bajo ningún alias buscado (fogonero, carbonero, bacaladilla, abadejo de Alaska) — "bacaladilla" existe pero es especie distinta, descartada como sustituto | USDA FoodData Central cuando el usuario compre el pescado real (fuente limpia para pescado: carbohidratos cero, no hay problema de convención neto/total) |
| Lenteja de bote, escurrida | BEDCA tiene "Lenteja, en conserva" pero esos valores son del bote entero con líquido de gobierno, no del producto escurrido (ver `NOTES_lenteja_conserva_peso_escurrido.md`) | Fuente externa, pendiente |
| Tortitas de maíz | No existe en BEDCA. Producto comercial de consumo habitual | Etiqueta |
| Muesli 0% azúcar | No existe en BEDCA | Etiqueta |

Ninguno de estos bloquea nada de lo sembrado hasta ahora (Fases 1-4a).
